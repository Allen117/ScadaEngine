**主要缺口摘要**（詳見逐條說明）：

1. **需量控制鏈路已閉環，級距抽象層仍缺**（2-1、4-15、4-16；2026-09-24 更新）：需量已虛擬點位化（`DMD-{kWhSID}` 三路發布），條件控制／LogicFlow／警報（Line/Email/SMS）皆可直接以需量值為條件觸發 — 超約卸載、警報通知可由使用者設規則達成。仍缺：無「契約容量」設定欄位與內建「需量級距」抽象層，多段級距需以多條不同閾值規則逐條近似，非單一整合式需量控制模組。
2. **無即時滾動曲線**（2-7、4-17 前半）：即時數據頁為表格式，曲線僅有歷史趨勢頁的查詢式圖表；圖表大小／顏色／Y 軸範圍等外觀客製不可設定。
3. **Windows 帳號整合（AD/SSO）無**（2-6(1)）：登入為自建 Cookie 認證。
4. **班別（shift）分段檢視無**（4-12）：僅有電費 TOU 尖離峰時段可作電費面向的近似替代。
5. **聲音／語音警報無**（2-13(3)(6)）：通知走 Line/Email/SMS 文字通道與畫面著色。
6. **VBScript 無**（4-13）：以 Python / C# 演算法、LogicFlow、NCalc 計算點為替代。
7. **OPC 僅 Client 端**（4-6）：對外分享走 MQTT / Modbus TCP Gateway，無 OPC UA Server。

## 第 2 大項：系統功能（2-1 ～ 2-21）

### 2-1 節約能源管制監控（需量控制、節電時序或定時控制）｜⚠ 部分符合

> 規格：可設定節電週期、設備時序、尖離峰運轉、契約容量、尖離峰用電限值進行監控，整合照明、空調等週邊設備，超載時自動卸載控制。品質標準另要求增設區域泵電錶及傳感器、既有圖控畫面增設相對圖面、報表符合冰機群組能源效率（kW/RT）規範。

- **依據**：功能說明書_排程設定、功能說明書_Engine核心 §9 條件控制／§10 LogicFlow、功能說明書_電費設定（TOU）、功能說明書_需量計算
- **具備**：排程設定（四種重複模式＋例外／加開日）＝節電週期；LogicFlow「A 接點—排程模式」＋條件控制可將時序／條件判斷寫回 Modbus 輸出，能對照明、空調等設備做定時、時序、尖離峰運轉控制；電費設定有 TOU 尖離峰時段。區域泵圖面可由 Designer 增設（見 4-8），kW/RT 報表能力見 2-15／2-18。
- **缺口**（2026-09-24 更新）：需量已虛擬點位化（`DMD-{kWhSID}` 進即時快取／LatestData，見 功能說明書_需量計算 §七之一），**條件控制／LogicFlow 可直接以需量值為條件觸發 Modbus 寫出（卸載）** — 超載自動卸載已可由使用者設規則達成。仍無「契約容量／尖離峰用電限值」欄位化的整合式需量控制模組，閾值需使用者自行換算設定。

### 2-2 內建資料庫及報表系統，儲存量大可長久保存｜✅ 符合

- **依據**：架構.md 資料表用途對照、功能說明書_需量計算 §八、功能說明書_資料庫自動建立與備份
- **說明**：內建 SQL Server（HistoryData／DemandData／EventLog／畫面設計 JSON 等），DB 自動建立、每週備份；歷史資料全量保留不自動清理；用電／電費／能源申報等報表系統齊備。

### 2-3 讀取數位電錶／電力轉換器數據，自動定時與不定時抄錶記錄｜✅ 符合

- **依據**：功能說明書_Engine核心（Modbus 採集、HistoryDataStorage 每 60 秒落表）、功能說明書_能源管理 §11（EnergyLeafHourly 逐時預聚合）、功能說明書_DB來源管理
- **說明**：Modbus／DB 來源／OPC UA 三管線採集電錶各量測值，Engine 定時（每 60 秒／每小時）自動落表；警報事件即時（不定時）記錄，完全免人工抄錶。

### 2-4 尖離峰時／日／月統計表與列印、制式電力計費報表、電費分攤、異常記錄分析｜⚠ 部分符合

- **依據**：功能說明書_能源管理、功能說明書_電費報表、功能說明書_電費設定、功能說明書_警報設定
- **具備**：用電／電費報表含時、日、月、年統計與 TOU 尖離峰電費；子迴路電費分攤（Sign 加權）；EventLog 異常事件記錄；Excel 匯出（ClosedXML）。
- **缺口**：報表輸出為 Excel 匯出，文件查無專門「列印」功能（可經瀏覽器列印或 Excel 端列印替代）；「制式電力計費報表」為系統自製格式而非台電標準單據版型。

### 2-5 電力品質與異常分析（電壓／電流／頻率／功因／諧波、SOE 查詢）｜⚠ 部分符合

- **依據**：功能說明書_能源管理（V/I/P/PF SID）、功能說明書_警報設定、功能說明書_歷史趨勢
- **具備**：電壓、電流、功率、功因可綁點位並自動記錄；警報事件寫入 EventLog；任一點位可查歷史趨勢圖。
- **缺口**：無專門諧波（THD）／頻率分析模組，有無此類數值取決於電表是否提供對應點位；EventLog 為警報觸發／恢復記錄，非嚴格意義的 SOE（事件序列）解析查詢。

### 2-6 安全管理（Windows 帳號整合、操作者權限、按鍵等級限制）｜⚠ 部分符合

- **依據**：功能說明書_登入 §4.2／§5.3／§12（角色體系、Permissions JSON、工程師模式）
- **具備**：(2) 每個操作者權限可規劃 — User 角色以 Permissions JSON 逐頁授權；(3) 按鍵／操作鈕等級限制 — SCADA 頁以 canView/canControl 逐頁分派檢視與控制權，低權限者看不到或不能控制；工程師模式六頁僅 Engineer 可見，直打 URL 也被 PageAccessFilter 阻擋。
- **缺口**：(1) **Windows 帳號整合（SSO）不符合** — 登入為自建 Cookie 認證（DB 帳號 SHA256），無 Windows AD 整合，登入 Windows 後仍須登入圖控系統。

### 2-7 即時曲線（大小自由設定、筆數不限、即時／歷史／內部點位、顏色自訂）｜❌ 不符合

- **依據**：功能說明書_即時數據（全頁表格式）、功能說明書_歷史趨勢 §7.5／§7.6
- **說明**：系統**無「即時曲線」元件** — 即時數據頁為表格式儀表板（每 3 秒輪詢），曲線僅存在於歷史趨勢頁（查詢式，非即時滾動）。(1) 圖表大小固定（單圖 380px／堆疊小圖 170px）；(2) 有筆數上限（每點 5000 筆、最多 8 點）；(3) 無即時滾動曲線；(4) 畫筆為固定 8 色循環，背景／邊框／顏色皆不可自訂。四子項皆缺。

### 2-8 即時曲線（使用者需求設定、即時繪圖、X/Y 軸規劃、取樣時間）｜⚠ 部分符合

- **依據**：功能說明書_歷史趨勢 §7.4／§7.6／§11
- **具備**：(8) 可設取樣時間（原始／1m／5m／15m／30m／1h）；(7) X 軸時間長度可自訂（起訖時間＋1h/6h/24h/3天/7天快捷）。
- **缺口**：(7) Y 軸為自動 ±10% padding 不可自訂；(6) 點名值對時間可繪圖但屬「按查詢繪出」非即時；(5) 無個人化（per-user）圖表設定。

### 2-9 歷史曲線（X 軸間隔／Y 軸範圍動態改變、區隔線數目）｜⚠ 部分符合

- **依據**：功能說明書_歷史趨勢 §7.4／§7.6／§7.8
- **具備**：(1) X 軸時間間隔可自訂且執行中可動態改變（改時間／間隔／圖表類型後重查即重繪）。
- **缺口**：(1) Y 軸數值範圍系統自動計算、不可自行規劃；(2) 無「主要／次要區隔線數目」設定（Chart.js 預設格線）。

### 2-10 歷史曲線（顏色設定、保存天數／儲存週期、動態控制）｜⚠ 部分符合

- **依據**：功能說明書_歷史趨勢 §7.7／§7.8、功能說明書_Engine核心 §6.2
- **具備**：(5) 執行中可動態改時間範圍／取樣間隔／單雙軸／折線柱狀並重繪。
- **缺口**：(3) 背景／畫筆／區隔線顏色不可設定（固定 8 色）；(4) 儲存週期固定每 60 秒、無設定介面；歷史保存天數無設定介面（現況全量保留）。

### 2-11 歷史曲線（縮放、列印、執行中改繪筆／起始時間）｜⚠ 部分符合

- **依據**：功能說明書_歷史趨勢 §7.3／§7.4／§11（Basket、時間範圍重查）
- **具備**：(8) 繪筆點名稱可執行中更改（Basket 增減點位後重查）；(9) 執行中可任意更改開始時間與時間長度。
- **缺口**：(6) 無曲線縮放（zoom）功能；(7) 無列印歷史曲線圖表功能（可經瀏覽器列印替代，文件未載明）。

### 2-12 警報處理（事件／系統故障警報、警報群組樹狀化）｜⚠ 部分符合

- **依據**：功能說明書_警報設定（三種警報類型、§13 系統 Fault 事件、§15 通知群組）、功能說明書_簡訊通知 §6
- **具備**：(1) 事件警報（上限／下限／DI，EventType=0）與系統故障警報（LogicFlow 控制寫入連續失敗 Fault，EventType=1）皆有。
- **缺口**：(2) 群組化僅有「通知收件群組」（Line/Email/SMS，數量不限、各自嚴重度路由），非「警報本身」的群組化；無警報群組樹狀結構。

### 2-13 警報處理（警報聲、優先等級、記錄檔設定、語音、看板設定、寫入資料庫）｜⚠ 部分符合

- **依據**：功能說明書_警報設定 §10（嚴重度）／§4（資料流）／§13（未恢復警報面板）
- **具備**：(4) 每條規則可設 0緊急／1高／2中／3低 四級嚴重度；(8) 警報觸發／恢復直接寫入 SQL Server EventLog 關聯資料庫。
- **部分**：(7) Designer 看板元件與顏色可自訂、警報面板可篩選出現項目（全部／僅未確認／僅已確認），但嚴重度色碼（紅橘黃灰）系統固定。
- **缺口**：(3) 無不同設備不同警報聲；(5) 無警報記錄檔起始時間／儲存週期／保存天數設定；(6) 無語音警報編輯與多媒體結合。

### 2-14 報表製作能力（警報或點資料報表）｜⚠ 部分符合

- **依據**：EventLog 頁 CSV 匯出、架構.md 用電／用水／用氣報表、功能說明書_能源日報
- **具備**：警報事件 CSV 匯出；多種點／能源報表（用電、用水、用氣、電費、歷史趨勢、能源日報）皆可 Excel 匯出。
- **缺口**：皆為預先定義報表，無使用者自訂報表產生器（report designer）。

### 2-15 冰機效率分析（即時總耗功率／總 RT／KW/RT 於主畫面）｜⚠ 部分符合

- **依據**:功能說明書_迴路資訊（空調水系統 RT·h）、功能說明書_能源申報／智慧助理對話窗（kWh/RTh 效率）、功能說明書_演算法服務（kW/RT、COP 演算法範例）、功能說明書_SCADA監控頁（即時數值元件）
- **具備**：kWh/RTh 效率已存在於冷凍噸報表、空調水系統迴路、能源申報、智慧助理區間效率；即時總耗功率、瞬時 RT、KW/RT 可用計算點位（含現成 kW/RT／COP 演算法）＋ ScadaPage 即時數值元件組出並顯示於監控主畫面。
- **缺口**：無現成的「冰機效率分析」主畫面把三值打包呈現，需以計算點位＋Designer 佈版建置（屬設定工作而非開發）。

### 2-16 空調系統基線設定｜✅ 符合

- **依據**：功能說明書_能源基線（Y=能源迴路或任意點位、X 含外氣溫濕度、複線性回歸／凍結／EnPI）、功能說明書_氣象資料來源
- **說明**：基線目標 Y 可選空調用電迴路（冰機／泵浦）或任意點位（冰機功率、RT、冷量），X 可綁外氣溫度／濕度／產量等，支援建模、凍結、EnPI 與節能量。小限制：空調水系統 RT·h 迴路（WaterCircuit）非基線「迴路」選項，需以「任意點位」方式選 RT／功率點位，功能面不受影響。

### 2-17 空調系統異常告警｜⚠ 部分符合

- **依據**：功能說明書_警報設定（通用上下限／DI 警報規則）、架構.md 空調水系統冷凍噸
- **說明**：可對空調相關點位（溫度、流量、功率、RT）以通用警報規則設定異常告警並走三通道通知；無「空調系統」專屬告警模組，屬以通用警報機制達成（實務上可涵蓋需求）。

### 2-18 空調冷凍噸計算（系統即時＋區間選定累計）｜✅ 符合

- **依據**：功能說明書_迴路資訊（RT 瞬時值 AVG×1h 積分、年／月／日）、功能說明書_能源管理 §11／§12（WaterLeafHourly 預聚合）、功能說明書_智慧助理對話窗（任意區間總 RT·h）、功能說明書_SCADA監控頁（累積量元件 integrate 積分模式）
- **說明**：即時 — 瞬時 RT 點位可於 ScadaPage 即時顯示，累積量元件可即時積分（當日／當月）；區間累計 — 冷凍噸報表（曆月）、空調水系統迴路（年／月／日）、智慧助理任意日期區間總 RT·h 皆具備。

### 2-19 跨廠區遠端管理（回傳泉生棟顯示、CH:KW/RT、CHP:COP、KW 監視畫面）｜⚠ 部分符合

- **依據**：架構.md（DB 來源 DBLatestData 對外寫入口、MQTT、Modbus TCP Gateway）、對外整合_MQTT即時資料訂閱、功能說明書_ModbusServerGateway
- **具備**：跨系統資料進出機制齊備 — 遠端站台可將數據寫入本站 DBLatestData（DB 來源管線）成為一般點位；對外有 MQTT 訂閱與 Modbus TCP Gateway；CH:KW/RT、CHP:COP、KW 可用計算點位／演算法產生後於 ScadaPage／EMS 呈現。
- **缺口**：無內建「跨廠區多站台管理」模組（MQTT Broker 為本機單站）、無站台切換主控台；泉生棟回傳需靠 DB 來源管線＋自建畫面組裝達成。

### 2-20 區域泵浦用電資訊蒐集（ZP1~10 新增電錶）｜✅ 符合

- **依據**：功能說明書_能源管理（/EnergyMeter 實體電表綁 SID、樹狀 CRUD）、功能說明書_Modbus來源管理（新增設備／多站號、熱編輯）
- **說明**：平台支援新增 Modbus 電錶設備並建立 ZP1~10 迴路節點（綁 kWh 點位、設 MaxKwh），即可蒐集用電並進報表／圖表。屬硬體加裝＋設定即可涵蓋。

### 2-21 區域泵浦流量資訊蒐集（ZP1~10 配合流量計）｜✅ 符合

- **依據**：架構.md（Modbus／DB 來源管線 → HistoryData／即時數據）、功能說明書_歷史趨勢（多點位查詢／匯出）；現況已有「冰水主管流量計」點位在用
- **說明**：流量計作為 Modbus 點位接入後，即時顯示、歷史趨勢、警報、Excel 匯出皆通用。註：無專屬「流量報表」頁；瞬時流量若需累計成體積，以積分計算點自建。

## 第 4 大項：能源管理系統軟體規格（4-1 ～ 4-20）

### 4-1 軟體授權：既有圖控系統擴充點數｜⚠ 部分符合

- **依據**：架構.md §HASP 授權守衛（LicenseBridge）
