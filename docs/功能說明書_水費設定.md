# 功能說明書 — 水費設定與水費報表

> 只做台水「**流動水費**」四級距分段累進（1 度 = 1 m³）；**不做基本費**（按口徑計收，非用量函數）、無 TOU / 季節。
> 用水量來源見 [功能說明書_用水報表.md](功能說明書_用水報表.md)；跨模組總覽見 [架構.md](架構.md) §用水報表與水費計算。

## 1. 設計決策：on-demand，不建 WaterCostHourly

電費需要逐時表（`ElectricityCostHourly`）是因為 TOU 每小時單價不同；水費只有分段累進，**成本 = f(期別總量)**，逐時成本無意義。
因此水費全部 on-demand：報表 / EMS 卡片當下由 `WaterMeterLeafHourly` 加總期別用水量再套級距，省掉一張表 + 一個背景服務 + 重算機制。

## 2. 費率方案（/WaterTariffSetting）

- 儲存：`SystemSettings.water_tariff`（整份 JSON），結構 = 方案列表，每方案含 **生效日** + 級距陣列。
- Seed：`ScadaEngine.Web/Setting/water-tariff-taiwater-defaults.json` — 台水流動水費預設：

| 級距（度/月） | 單價（元/度） |
|---|---|
| 1–10 | 7.35 |
| 11–30 | 9.45 |
| 31–50 | 11.55 |
| 51 以上 | 12.075 |

- **方案版本（生效日）**：計算某期水費時依「期別**起日**」選用當時生效的方案（生效日 ≤ 起日中最新者；都不合則取最早方案）。改費率新增一版即可，**歷史期別水費不被追溯改寫**。
- 驗證（`WaterTariffService.ValidatePlan`）：第一級從 1 起、級距連續遞增、僅末級上限可為「以上」（null）、單價非負、生效日 yyyy-MM-dd。
- 級距按「每月一期」直接套用 — 台水大用水戶（工廠/機關/商用，本系統目標場景）為每月抄表一月一單；「兩月一期、級距×2」僅一般家庭小用戶適用，不在本案範圍。

## 3. 水費計算（WaterCostService）

- 計費週期共用 `BillingPeriods` 月結期別（`BillingPeriodService`，與電費對齊）。
- 每迴路**獨立**對自身期別總用水量套分段累進（無占比分攤；分段演算法同電費 progressive：`lower = nFrom-1`、`upper = nTo ?? ∞`、逐級 slice × 單價）。
- 純邏輯 `ApplyTiers` / `SelectPlanForDate` 為 public static，單元測試鎖規則：
  `ScadaEngine.Tests/WaterMeter/WaterCostServiceTests.cs`（10/30/50 邊界、0 度、超大量、小數）、`WaterTariffServiceTests.cs`（驗證 + seed + 版本選擇）。

## 4. 水費報表（/WaterCostReport）

- 選迴路 + 起訖月（期別區間）→ 每期一列：期別、用水量（m³）、套用方案（含生效日）、水費，可展開級距明細。
- 切換歷史期別時採用**該期起日生效**的方案版本。
- Excel 匯出：`WaterCostReportExcelExporter`（ClosedXML，i18n resx）。

## 5. EMS 水費狀態卡（WaterCost）

- 預設樹根迴路（全廠），可下拉切換迴路；顯示本期（`GetCurrentPeriodAsync`）用水量、各級距 slice 明細、流動水費合計。
- 未設定方案（config 無方案）→ 卡片顯示「尚未設定水費方案」引導。
- API：`GET /EMS/api/water-cost?circuitId=`。
